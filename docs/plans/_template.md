# 开发计划：plan-w{N}-{scope}

> 使用说明（创建后删除本行）：从本模板复制为 `plan-w{N}-{scope}.md`（周计划）或 `plan-sp-{topic}.md`（专项计划），在 `00-overview.md` 登记后生效。计划是**活文档**：状态/勾选/进度日志就地更新，不进版本号（命名规范见 `docs/00-index.md`）。

| 项 | 内容 |
| --- | --- |
| 计划编号 | plan-w{N}-{scope} |
| 对应 spec 章节 | §X.X、§X.X（范围与验收的出处，计划不得超出该范围） |
| 状态 | 未开始 / 进行中 / 已完成 / 已裁剪 / 阻塞 |
| 计划开始 | YYYY-MM-DD |
| 计划完成 | YYYY-MM-DD（周末，打 tag `w{N}`） |
| 前置依赖 | 其他计划编号（含 Phase 级依赖）或「无」 |
| 分支约定 | `feature/w{N}-{scope}`（整个计划一条分支，或按 Phase 分支） |
