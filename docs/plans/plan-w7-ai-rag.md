## 1. 目标（一句话）

`buildcloud-module-ai` 可演示：文档上传→分块向量化→RAG 问答（SSE 流式 + 会话记忆 + 引用溯源），LLM 供应商/模型/Key 全动态配置（Nacos）+ Token 限流，20 条评测集答对率 ≥ 80%。

## 2. Phase 清单（Phase 4 可与 Phase 2/3 ∥ 并行；其余串行）

### Phase 3：RAG 问答全链路

## 3. 计划级验收标准（出口条件，来自 spec §9 W7）

- [ ] 评测集答对率 ≥ 80%（引用正确即算对）；
- [ ] 流式输出稳定；
- [ ] 供应商切换演示通过（D19）；
- [ ] buildcloud-ai 可演示（上传→问答→引用全链路）；
- [ ] tag `w7` + 状态同步 + 进度日志收尾。

## 4. 涉及范围（改动声明）

- 代码模块：`buildcloud-module-ai`（唯一 Java 模块）+ 网关 SSE 配置；
- 数据库/SQL：MySQL 3 表 + PG chunk 表；
- 配置/Nacos：LLM 动态配置项（模板化，无 Key 明文）；
- 文档：`design-ai.md`、评测集、评测记录。
