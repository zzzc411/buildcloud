# 开发计划拆分总览

> 本文件跟踪从 [spec v1.0](../spec/buildcloud-spec-v1.0.md) 拆分出的全部开发计划。每个计划是一个可独立执行、可独立验收的工作包。
> 状态：`未开始 / 进行中 / 已完成 / 已裁剪 / 阻塞`。裁剪 = 触发 spec §9 超支预案。

## 拆分原则

1. **一计划一出口**：每个计划有明确交付物与验收标准（来自 spec 对应表格行）；
2. **从模板创建**：所有计划从 [`_template.md`](_template.md) 复制，编号 `plan-w{N}-{scope}.md`；
3. **不扩权**：计划细化任务，不新增范围；新增范围 = 回 spec 升版本或记 ADR（`docs/decisions/`）；
4. **大小适中**：一个计划 ≈ 3~7 个工作日；同周可拆多份（如 W5 高并发可拆 Lua 预扣 / 事务消息 / 对账三份）。

## 使用方式（人 & 智能体一致）

- 开工某计划前：复制模板 → 填写 → 在本表登记状态「进行中」；
- 计划进行中：每日更新「进度日志」小节（一句话即可）；
- 完成后：勾完验收清单 → 状态改「已完成」→ 在 `00-index.md` 登记表登记。
