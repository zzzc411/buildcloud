## 1. 目标（一句话）

公开仓库**零密钥泄漏**成为可执行、可验证的日常纪律：配置全模板化、注入机制文档化、扫描脚本化，LLM Key 的注入方案（供 W7 用）提前设计。

## 2. Phase 清单（每个 Phase = 一次子智能体派发单元）

### Phase 1：配置模板化规范落地

| 项 | 内容 |
| --- | --- |
| 工作量 | 1d（并入 W2 Phase 2 执行） |

## 3. 计划级验收标准（出口条件）

- [ ] 模板化 + 扫描 + 注入文档 + LLM Key 方案四件套齐备；
- [ ] W2 裁剪验收中的「密钥泄漏扫描通过」条款由本计划背书；
- [ ] 长期条款生效：每次提交前自查（AGENTS §5），发现泄漏立即历史改写 + 换 Key（R8）。

## 4. 涉及范围（改动声明）

- 代码模块：无业务代码（脚本 + 配置模板）；
- 数据库/SQL：无；
- 配置/Nacos：全部配置文件模板化（核心改动）；
- 文档：`docs/ops/secret-management.md`、ADR。
