# 开发计划：plan-sp-demo-seeding（造数脚本与演示数据）

| 项 | 内容 |
| --- | --- |
| 计划编号 | plan-sp-demo-seeding |
| 对应 spec 章节 | §8.1（造数脚本）、§2.1（组织角色模型）、§2.3（压测场景设定） |
| 状态 | 未开始 |
| 计划开始 | W3 结束后即可启动（表结构定型），不晚于 2027-01-08 |
| 计划完成 | 2027-01-10（**硬约束：W6 Phase 5 压测前百万流水必须就绪**） |

| 分支约定 | `feature/sp-seeding` |

## 1. 目标（一句话）

一键生成两套数据：**演示数据**（六域端到端演示脚本用的小规模真实感数据）与**压测数据**（N 项目 × M 物料 × 百万级流水，分片分布均匀），可重复执行、可清空重灌。

## 2. Phase 清单（每个 Phase = 一次子智能体派发单元）

### Phase 1：基础演示数据

| 项 | 内容 |
| --- | --- |
| 工作量 | 1d |
| 任务 | 一家建筑公司（单租户）+ 组织角色（spec §2.1 六角色）+ 部门树；2-3 个项目全状态覆盖（筹备/在建/停工/竣工）+ 里程碑/成员；合同/计划/收付记录；物料目录/供应商/库存若干；SQL 脚本（可重复执行，幂等） |
| 交付物 | `sql/buildcloud/seed-demo.sql`（或脚本生成器）+ 使用说明 |
| 验收标准 | [ ] 演示脚本（W4/W8）依赖的数据齐全；[ ] 幂等可重灌（先清后插）；[ ] 数据符合业务逻辑（在建项目才有申领记录等） |
| 上下文包（必读） | spec §2.1、§2.2；W3/W4 的表结构 SQL |
| 状态 | ☐ |

### Phase 2：百万级压测数据

| 项 | 内容 |
| --- | --- |
| 工作量 | 1.5d |
| 任务 | 造数程序（Java 或 SQL 过程）：N 项目（≥50）× M 物料（热点物料集中分布，模拟 §2.3 场景）× 100 万级 stock_log 流水；**按 project_id 哈希分布到 4 schema**（与分片路由一致）；可分批生成（不锁库） |
| 交付物 | 造数程序/脚本 + `docs/testing/seed-data.md`（数据规格说明：规模/分布/热点设计） |
| 验收标准 | [ ] 100 万流水分布均匀（各 schema 差异 <10%）；[ ] 热点物料库存记录就位（压测同库存记录并发申领场景）；[ ] 重灌耗时与资源可控 |
| 上下文包（必读） | spec §2.3、§6.3（分片键分布）、§8.2（压测矩阵）；W6 Phase 2 分片配置 |
| 状态 | ☐ |

## 3. 计划级验收标准（出口条件）

- [ ] 两套数据一键生成 + 一键重灌；
- [ ] `seed-data.md` 说明数据规格（W6 压测报告环境记录引用）；
- [ ] W6 Phase 5 压测开跑前完成（硬时间点）。

## 4. 涉及范围（改动声明）

- 代码模块：造数工具（独立目录，不污染业务模块）；
- 数据库/SQL：seed 脚本 + 分片 schema 数据；
- 配置/Nacos：无；
- 文档：`docs/testing/seed-data.md`。

## 5. 风险与回退

| 风险 | 对策 |
| --- | --- |
| 造数与分片路由不一致 | 分布校验脚本输出（Phase 2 验收项）；不一致先修造数不改路由 |
| 大量插入拖垮本机 | 分批 + 限速；必要时停部分服务再灌 |
